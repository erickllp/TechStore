# TechStore

Aplicação web de uma loja online de tecnologia, desenvolvida com **Angular**, **HTML**, **CSS** e **TypeScript**.

Este é um projeto de estudo e está em desenvolvimento. O código será atualizado aos poucos, e o histórico de commits mostra a evolução do projeto.

## Tecnologias

- Angular
- TypeScript
- HTML5
- CSS3

## Funcionalidades

- [x] Página de login
- [ ] Página de cadastro
- [ ] Catálogo de produtos
- [ ] Carrinho de compras
- [ ] Finalização de pedido

> A lista é atualizada conforme o projeto avança.

## Como rodar o projeto

Pré-requisitos: [Node.js](https://nodejs.org/) e Angular CLI.

```bash
# clonar o repositório
git clone https://github.com/SEU-USUARIO/techstore.git

# entrar na pasta
cd techstore

# instalar as dependências
npm install

# iniciar o servidor de desenvolvimento
ng serve
```

Depois, acesse `http://localhost:4200` no navegador.
